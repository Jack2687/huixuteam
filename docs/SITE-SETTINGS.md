# 站点设置

入口：页面右上角的运营控制台 → 站点设置，左侧不再显示运营控制台。只有管理员账户收到并显示该入口；运营人员和普通用户的导航响应不含后台菜单，也不能访问任何后台页面、接口或 JS/CSS。仅管理员具有 `admin.site.manage` 权限，可以读取或修改站点设置、查看邮件记录及测试邮件服务。

## 品牌与服务

站点设置 → 品牌与服务，上传站点图标，预览后点击“保存图标”。图标同步用于登录页、左侧品牌标识与浏览器标签；默认使用回序专属深绿暖金图标，可随时恢复默认。其他用户在下次页面刷新或工作台配置刷新时更新图标。

支持 PNG/JPG（最大1MB，宽高最大2048像素）及静态SVG（最大16KB），建议正方形256×256。服务端按实际内容验证格式，位图解码后重新编码为PNG，SVG只允许静态图形、不允许脚本或外部引用。图标保存在独立的 PostgreSQL 配置表中，更新或重建应用不覆盖已上传图标；恢复默认不修改其他站点设置。

只有管理员可读取管理配置、上传或恢复图标；图标图片与用于展示的URL属于公开品牌资源，访客登录页也可读取。后台编辑界面仍在受权限保护的管理代码包中，普通用户不能访问修改接口。

注册默认服务单价初始为100积分，可在本页配置为0～100000积分，支持两位小数。保存后仅影响后续注册；既有用户保留独立单价。后台新建用户也预填当前配置，仍可单独修改。

## 功能开关

默认保留全部现有前台功能。可独立开启服务总览、申请记录与提交、资金与账单、接口接入、公告中心和使用指南。

前台导航从服务端获取，普通用户的导航响应没有运营控制台。关闭功能同时拒绝其 API、直接页面地址和独立 JS/CSS 模块请求，返回 404；修改页面或重放请求不能恢复访问。后台代码包有独立身份和权限检查，普通用户即使知道地址也会收到 403（未登录为 401）。已经下载过的静态文件无法从用户设备撤回，但服务端权限始终有效。

接口接入开关同时控制 API 密钥管理、开放 API 和接口手册。申请开关同时控制网页及开放 API 的提交、查询和撤回。关闭功能不清空数据、不取消已受理任务、不改变申请工作者、冻结或结算规则。账户消息仍然提供，方便用户收到原任务结果。后台管理入口由权限控制，不属于可关闭的前台功能。

## 自定义菜单

站点设置 → 自定义菜单，可以新增、修改、删除、启用/停用和上下移动菜单，最多 20 项。菜单名称、页面 URL、可见角色和 SVG 图标均可配置，调整后点击“保存自定义菜单”生效。未上传图标时使用默认链接图标；SVG 限 16KB，仅接受静态图形。

- 普通用户：登录用户可见，包含管理员和运营人员。
- 仅管理员：只有管理员可见；普通用户和运营人员的导航响应不包含该菜单、名称、URL 或图标。菜单详情、图标、直接页面地址和打开链接的跳转入口均由后端重新校验权限。
- 点击菜单时新窗口打开：开启后点击侧边栏菜单直接在新标签页打开目标网站，当前工作台保持；关闭时在工作台内嵌显示。
- 隐藏内嵌页的“新窗口打开”按钮：仅控制内嵌页面上的备用打开入口，与点击菜单直接打开新窗口是两个独立选项。

页面 URL 必须为完整 HTTP/HTTPS 地址，不接受脚本协议、相对路径或包含账号密码的地址。系统不会把用户登录凭据、API 密钥或用户资料拼接到外部网址。内嵌页使用浏览器沙箱和无来源信息策略；目标网站拒绝 iframe、需要受限的浏览器存储或与内嵌环境不兼容时，应选择新窗口打开。HTTPS 站点内嵌 HTTP 页面还会受浏览器混合内容规则限制。

禁用或删除菜单后，其详情、图标和站内跳转入口立即返回 404；调整可见角色后，原无权限用户请求返回 403。已打开的外部网站、用户已经知道的外部网址仍由目标网站管理访问权限。菜单配置不会下发给未登录访客，配置保存写入操作留痕，服务重启不会重置。

## 安全与认证

- 开放注册：默认关闭，保持现有站点准入规则。开启后新用户只能成为普通用户，初始积分为 0，服务单价读取「品牌与服务」中的注册默认服务单价（初始100积分）。
- 邮箱验证：默认开启；开放注册且要求邮箱验证时，必须先保存可用的 SMTP 配置。关闭后注册不要求验证码，不影响忘记密码的邮箱验证。
- 邮箱域名白名单：留空允许所有域名。支持 `qq.com`、`@qq.com`、`*.example.com`；通配写法包含主域名及子域名，匹配有域名边界。白名单仅限制新注册，不阻止已有用户登录或找回密码。
- 忘记密码：SMTP 配置完整时提供入口，不依赖是否开放注册。用户通过邮箱验证码设置新密码。重置成功后旧登录会话、旧 API 密钥失效，需要重新登录并按需创建新密钥。

验证码由安全随机数产生，15 分钟有效，重发至少间隔 60 秒；每份验证码最多允许 5 次错误尝试，只能消费一次，并与邮箱及用途绑定。验证码摘要使用主密钥派生的 HMAC 密钥，明文仅存在于加密的待发邮件中。注册/重置与消费验证码在同一数据库事务中，并发不能重复消费。重置验证码还绑定发码时的用户身份和密码版本。

发码和提交接口均有独立、持久化的邮箱/IP频率限制，即使关闭可选风控监控也生效。未知、停用或删除账户请求密码重置时，响应与正常请求保持相同文案，不发送真实邮件、不暴露账户存在性。密码长度沿用现有站点的 12～72 字节要求。

## 邮件设置

填写 SMTP 主机、端口、加密方式、用户名、授权密码、发件邮箱和发件名称。支持 TLS（通常 465）、STARTTLS（通常 587）；校验证书，不降级到不安全认证。无加密仅供不需要账号认证的中继。用户名留空适用于免认证中继，实际公网邮件建议使用 TLS 或 STARTTLS。

授权密码用已有 MASTER_KEY 加密存储，读取设置仅返回是否已配置；保存时密码留空保留原值。修改记录不保存授权密码。先保存后使用“测试连接”（不发送邮件），或填写收件邮箱使用“发送测试邮件”。

邮件由独立后台队列发送，不等待 SMTP 才返回发码请求，不占申请执行工作者。网络有超时，失败每隔 30 秒重试，最多 3 次；重启后可恢复未完成的邮件。过期、已使用、被替代的验证码邮件不再发送。DATA 已确认接收后不因 QUIT 失败重新发送。极端情况下 SMTP 已接收但进程在记录结果前退出，可能重复投递同一验证码，不会因此重复注册或重置密码。

邮件管理记录收件邮箱、用途、发送状态、尝试次数、创建/发送时间和固定错误类别；不返回正文、验证码、SMTP响应或密码。发送完成或最终失败后删除加密正文。记录保留 30 天，过期验证码与限流窗口定期清理。实际是否投递进收件箱还取决于邮箱服务商配置，可使用测试邮件验证。

## 验证

Go 测试覆盖管理员权限、后台模块隔离、功能禁用、域名规则、注册策略、验证码重放/耗尽/并发、密码重置后凭证撤销、SMTP加密不降级及有限重试。真实 SMTP 收发链路仅对本机模拟收件服务执行。

`scripts/browser-site-settings.py` 使用专用 `huixu_site_qa_*` 数据库、18743 端口及本机 SMTP 收件服务，覆盖三个设置面板、验证码注册、忘记密码、普通用户未加载后台模块、越权拒绝和手机布局。不得把该测试脚本指向正式环境或迁移前本机业务数据库。

本次新增的配置和邮件表自动迁移；重复启动只补缺失结构，不重置已有站点配置。后续上线依旧按既有流程保留正式 `.env`、MASTER_KEY、业务数据及配置，不迁移本机 QA 数据。
