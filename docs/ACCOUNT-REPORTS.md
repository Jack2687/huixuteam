# 账户报表

运营控制台的「账户报表」仅管理员可见，接口也按管理员权限校验。默认排除管理员账号，可取消勾选纳入；支持姓名、邮箱搜索，默认每页 100 人。汇总覆盖全部筛选结果，不受当前页影响。

- 日、周、月、年均采用北京时间自然周期，周一为一周起点；可选历史日期和前后周期。
- 期间充值：人工入账与兑换码入账之和。人工扣减单独列出，不算服务消费。
- 当前冻结：查询时尚未结算或释放的积分；期间新增冻结、期间释放另列。结算也解除对应冻结，同时计入已使用。
- 期间已使用：所选期间实际结算的历史费用；之前提交、本期完成的申请也计入。修改单价不追溯修改已结算费用。
- 服务单价：当前用户配置价；另列本期结算的平均实收。申请按提交时锁定的单价执行。
- 当前可用余额 = 当前总余额 − 当前冻结。查询历史周期时，余额及当前冻结仍表示最新值。
- 期间申请：按提交时间归属周期，进展显示查询时的最新状态；未成功包括失败和受限申请。

金额单位为积分，1 积分 = 1 R。报表仅返回账户身份、财务汇总和通用申请状态，不包含办理凭据、内部协议或原始上游数据。

登录页及服务总览公告自动向左连续滚动，悬停或聚焦可暂停，支持手动暂停及点击完整阅读。系统开启减少动态效果时改为静态可滚动显示。
