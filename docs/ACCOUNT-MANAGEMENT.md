# 账户资料与删除

运营控制台的账户管理仅允许系统管理员修改登录邮箱、账户称呼、角色与服务费，或删除账户。邮箱统一去除首尾空格并转换为小写，重复或无效地址会拒绝保存。修改邮箱后原登录会话失效，需用新邮箱登录；账户 ID、历史账单与既有 API 密钥保持不变。修改初始化管理员邮箱后，服务重启不会重新创建旧邮箱。

删除需要在页面二次确认。删除后账户不再出现在账户管理列表中，不能登录、发起申请、获得新密钥或继续充值；原会话删除，原 API 密钥撤销。历史申请、积分账单、审计记录与报表保留，剩余积分不会自动扣除。历史邮箱仍保留，不能重新注册为另一个账户。

有未结束申请或已预留积分的账户不能删除，即使申请的服务费为零也一样。不能删除当前登录管理员，且必须保留启用的管理员。删除与新申请在同一账户行锁下互斥，避免删除后仍有申请进入执行队列；重复删除不重复记账或写审计。

本功能操作的是回序服务账户，不操作客户申请中的上游账号。所有修改均由服务端检查权限并记录操作留痕。
