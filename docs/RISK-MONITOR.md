# 风控监控

入口：运营控制台 → 风控监控。右上角“配置”打开独立配置页面。仅管理员拥有读写权限，运营人员、普通用户和对外 API 密钥不可访问，包括管理静态资源。

## 默认配置

| 规则 | 次数 / 窗口 | 超出后限制时长 | 默认模式 |
| --- | --- | --- | --- |
| 登录尝试 | 每账号 10 次 / 900 秒 | 900 秒 | 执行限制 |
| 兑换积分 | 每客户 20 次 / 60 秒 | 60 秒 | 执行限制 |
| 提交申请 | 每客户 30 次 / 60 秒 | 60 秒 | 仅告警 |
| 查询与轮询 | 每客户 300 次 / 60 秒 | 60 秒 | 仅告警 |
| 其他业务操作 | 每客户 60 次 / 60 秒 | 60 秒 | 仅告警 |
| 客户总请求量 | 每客户 600 次 / 60 秒 | 60 秒 | 仅告警 |
| 单个 API 密钥 | 每密钥 300 次 / 60 秒 | 60 秒 | 仅告警 |

全部规则支持关闭、仅告警、执行限制，以及独立的次数、窗口和限制时长。次数按 HTTP 请求计算，一次批量提交仍计一次，原批量条数、余额、重复账号及幂等校验继续执行。客户总量与接口类型在不同 API 密钥之间累计，无法通过切换密钥绕过。

限制计数保存在 PostgreSQL，重建应用不会清空；超过上限的请求返回 429 和实际剩余 Retry-After。被拒绝的重复请求不会无限延长限制。到期、手动解除或修改该规则后重新计数。成功登录仅重置本账号的登录计数，共用反向代理或 IP 不会连带限制其他账号。

客户独立配置可以覆盖非登录规则的最大次数，模式、窗口和限制时长沿用全局。仅暂停新申请支持手动恢复或指定自动恢复时间；已受理任务继续执行，原申请幂等重放、查询和撤回不受该暂停影响（其他独立频率限制仍适用）。后台风控接口、管理员身份读取与退出登录保持可达，便于恢复误限制。

## 监控范围

- 登录成功/失败、认证失效、权限拒绝、业务接口错误、限流与仅告警记录。
- 重复提交、集中撤回、近期申请失败比例、排队数量、排队和办理超时。
- 大额积分调整、预留积分与冻结申请总额不符、服务费结算账单缺失或金额不符。
- 账户、积分、兑换码、服务配置和风控管理操作，使用固定业务描述。
- 按客户、密钥、网页/API 和业务类型汇总请求数、错误数、拦截数、平均响应时间。

默认：页面 10 秒刷新；后台 60 秒检查；记录保留 30 天；异常行为窗口 900 秒；已核实来源尝试账号数 10、重复提交 10 次、撤回 10 次；至少 5 笔结束申请且未完成比例 ≥50%；单客户排队 ≥20 笔、排队超过 600 秒、办理超过 900 秒；单笔积分调整 ≥1000 积分（1 积分 = 1 R）。上述数值均可配置。统计日期按北京时间，事件默认每页 100 条；当前限制独立显示全站生效项，不受事件日期筛选影响。

异常检查只告警，不自动暂停客户、取消申请或调整积分。事件“标记已处理”不会解除限制；限制需在“当前限制”单独解除。同一持续异常不会每次扫描重复告警；异常消失后再次出现会形成新事件。降低保存天数仅清理超期风控记录，不删除业务申请、积分账本或原审计。

## 来源与信息隔离

可信代理配置默认留空，来源显示“未核实”，不执行跨账号来源告警。配置核实后的代理 IP/CIDR 后，仅信任来自该代理的 X-Forwarded-For 链，从连接端向客户端逐级解析。不信任任意客户提交的 CF-Connecting-IP 或 X-Real-IP，不以 IP 对多个账号实施封禁。

风控只收集固定的业务标签、用户/密钥编号及名称、合法 IP、状态码、耗时和次数。不保存请求体、密码、2FA、完整 API 密钥、请求头、原始路径、内部执行状态或上游错误。客户端不会新增任何核心上游请求。配置与管理操作留审计，配置使用版本号防止覆盖其他管理员的新修改。

关闭“记录风控事件、访问统计并检查业务异常”后不再生成新记录，但已经启用的限流仍执行。恢复记录不会补采停用期间的访问统计。已有业务审计可在保留范围内被后台归纳为管理操作记录。
