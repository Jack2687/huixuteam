# 登录与兑换使用报表（2026-11-05）

网页登录在验证密码后签发会话时，持用户行锁重新核对密码、邮箱与可用状态。期间改密、改邮箱或停用的旧登录不能签发新会话；校验凭据仅保留在服务端，不进入 JSON。

兑换码管理新增“使用情况”，按北京时间自然日/周/月/年筛选，周一为周起点。依据实际兑换时间查询历史 redemptions；明细分页和汇总共享只读快照，统计兑换次数、不同码数量、使用人数及实际入账积分。历史多次兑换、已软删除用户和码的财务历史仍保留，接口需要 admin.codes.manage。

管理列表及使用情况均支持完整兑换码精确搜索，规范大小写和首尾空格后匹配哈希，不解密整张表。前缀、备注与邮箱仍可搜索，百分号和下划线按字面匹配；响应不返回完整码或密文。前端独立管理包继续受管理权限保护。

总览和运营概况显示“敏感数据已加密保护”。此提示不代表所有可检索业务字段均已加密。

验证覆盖旧登录竞态、报表日界线、分页/汇总一致、历史多次兑换、删除账户、完整码搜索及匿名/普通用户权限；完整 Go 测试、go vet、前端测试/构建和桌面/手机浏览器交互已执行。仅使用独立测试数据，无真实业务操作。
